## Consolidated confirmed findings

### P0 — must repair before Phase 0 can pass

1. `am3d/recipes/executor.py` exports `.am3d` through the raw serializer and drops actions, active action, assignments, and related Session state. Repair through the Session save path and prove fresh-session round-trip.
2. Recipe execution replaces/mutates a caller-provided live Session before success is known. Build in an isolated candidate session and publish only on success; failed runs must preserve the prior session.
3. Recipe output paths are not confined to an explicit output root. Canonicalize, reject absolute/traversal escapes and collisions as required, and report the offending field path.
4. The CLI/executor do not provide a stable structured failure envelope for parse/schema/runtime/write errors. Define stable code, stage, field path, message, and correction hint, with documented exit codes and one JSON result in machine mode.
5. Unsupported recipe versions and meaningful unknown fields are accepted or silently discarded. Add version validation and explicit unknown-field policy/conformance tests.
6. Material texture/pattern/params/graph/object or patch bindings are dynamic/unserialized, and OBJ/GLB writers emit no supported material references. Make the chosen supported material representation explicit and durable.

### P1 — required by later V3 gates; schedule in owning phase

7. Recipe and GUI export paths do not share scene evaluation; action frames, skinning, visibility, and transforms are not consistently applied to exported/rendered geometry.
8. Object normals use the linear transform instead of inverse-transpose under non-uniform scale.
9. Retargeting passes target bones as both source and target and cannot represent unequal rigs.
10. Malformed serializer arrays can be silently truncated by `zip`; enforce shape/count/finite-value limits and field-specific errors.
11. Autosave is not scheduled and recovery cleanup is not per-document.
12. Windows build root/smoke checks and packaged headless recipe entry point are incomplete.
13. Settings are persisted but not wired to the application behavior.

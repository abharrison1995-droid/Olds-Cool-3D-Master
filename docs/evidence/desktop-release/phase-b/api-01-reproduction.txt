Three rows are silent-wrong-result defects, not merely poor messages:

  nu=1        16 vertices, ZERO triangles. A caller gets an empty surface with
              no error at all.
  degree_u=0  accepted; a degree-0 tensor-product surface is a set of
              disconnected constant spans, not a surface.
  weights=0   every vertex collapsed onto the origin:
                build_patch_grid(g, weights_u=[0,0,0,0])[0][:2]
                -> [[0. 0. 0.]
                    [0. 0. 0.]]
              The rational basis divides by the weight sum; all-zero gives 0/0
              resolved to the origin with no warning. A negative weight
              (weights_u=[1,-1,1,1]) drives the denominator toward zero.

The remaining rows raise, but with numpy-internal messages that name no
parameter of this API, so a caller cannot tell which argument was wrong.

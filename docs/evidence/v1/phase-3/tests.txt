Follow-up on the intermittent Windows audit failure:
The root and all resolved descendants in `_verify_tree` now pass through `extended_io_path(os.path.realpath(...))` before `commonpath`. This is comparison-only host-path normalization; it does not change portable recipe path validation, link checks, output allowlists, or strict post-exit auditing.
The installed CPython 3.12 `ntpath.realpath` implementation can retain a `\\?\\` prefix when a file disappears between final-path probes. For a contained file, that can pair an ordinary root path with an extended child path, for which `ntpath.commonpath` raises `ValueError`. The original intermittent occurrence's traceback detail was not captured, so this mechanism is recorded as a source-confirmed match to the observed exception class, not as a captured stack trace.
